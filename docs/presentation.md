> **การจองทดลองขับและซื้อรถออนไลน์** ซึ่งคาบเกี่ยวกับอีก 2 อุตสาหกรรมคือ
> **ค้าปลีกสินค้าราคาสูง (high-consideration retail)** และ **การเงิน/สินเชื่อรถยนต์**
>
> Persona ของเราคือคนทำงานที่อยากได้รถ แต่ปัญหาคือ ต้องวิ่งหลายโชว์รูมเพื่อเทียบสเปคกับราคา

## 0:40–1:20 — โปรเจกต์ทำอะไร

> "ASTRA Motors คือเว็บแอปที่ทำ journey การซื้อรถให้จบได้บนเว็บทั้ง 8 ขั้นตอน:
>
> 1. เปรียบเทียบรุ่นรถแบบเคียงข้างกัน
> 2. เลือกสี/ออปชัน — ราคาอัปเดตทันที และดูรถเป็นโมเดล 3 มิติหมุนดูรอบคันได้
> 3. คำนวณไฟแนนซ์ เทียบเงินดาวน์/งวดผ่อนจากหลายสถาบัน
> 4. จองทดลองขับ เลือกโชว์รูมและเวลาที่ว่างจริง
> 5. วางเงินจองออนไลน์ ล็อกราคาไว้ 14 วัน
> 6. ยื่นขอสินเชื่อพร้อมแนบเอกสาร
> 7. ติดตามสถานะการอนุมัติ
> 8. นัดวันรับรถ
>
> เทคโนโลยีคือ **FastAPI (Python) + HTML/CSS/JavaScript ธรรมดา** ทั้งหมดรันด้วย
> **Docker Compose** คำสั่งเดียว โดย FastAPI ทำหน้าที่ทั้งเป็น REST API และ serve หน้าเว็บในคอนเทนเนอร์เดียว
> ส่วนสัปดาห์นี้เราเพิ่ม **REST API ระบบสมาชิกและจัดการผู้ใช้** ครบ 10 endpoint"

## 1:20–2:10 — ทำไมถึงเลือกโปรเจกต์นี้ (พร้อมเหตุผล)

> "มี 4 เหตุผลครับ
>
> **หนึ่ง — journey ยาวและมีจุดตัดสินใจเยอะที่สุดในเอกสาร** 8 ขั้นตอน ทำให้เราได้ฝึกครบทั้ง
> CRUD, validation, การจัดการสถานะ และ edge case มากกว่าระบบจองคิวทั่วไปที่จบใน 3 ขั้นตอน
>
> **สอง — เป็นปัญหาที่เจอจริง** การซื้อรถหนึ่งคันคือการตัดสินใจครั้งใหญ่ที่สุดครั้งหนึ่งของคนทำงาน
> แต่ข้อมูลกลับกระจัดกระจาย ต้องเดินหลายโชว์รูม
>
> **สาม — มี business logic ที่คำนวณจริง ไม่ใช่แค่ฟอร์ม** ยอดผ่อน ดอกเบี้ย เงินดาวน์ เงื่อนไขเงินคืน
> เกณฑ์อนุมัติสินเชื่อ ทำให้เขียนโค้ดฝั่ง backend ได้มีสาระ ไม่ใช่แค่รับข้อมูลไปเก็บ
>
> **สี่ — ต่อยอดได้ตรงกับ roadmap ของวิชา** สัปดาห์นี้ทำ auth + REST API,
> สัปดาห์หน้าย้ายลง PostgreSQL ที่เตรียม container ไว้แล้วใน docker-compose แล้ว deploy จริง"

## 2:10–3:00 — มี feature ต่างจากระบบอื่นหรือไม่

> "มีครับ 4 อย่างที่เว็บโชว์รูมทั่วไปไม่ทำ
>
> **1. ล็อกราคาให้ลูกค้า** เว็บส่วนใหญ่บอกแค่ราคาวันนี้ ของเราออกใบจองแล้ว **ล็อกราคาและโปรโมชั่น 14 วัน**
> ต่อให้โปรโมชั่นหมดอายุหลังจากนั้น ใบจองใบนั้นก็ยังได้ราคาเดิม
>
> **2. เส้นทางสำหรับคนที่สินเชื่อไม่ผ่าน** ระบบทั่วไปขึ้นแค่ 'ไม่อนุมัติ' แล้วจบ
> ของเราคำนวณให้ว่าถ้าเพิ่มเงินดาวน์เท่าไร หรือยืดงวดเป็นกี่เดือน ถึงจะผ่านเกณฑ์ พร้อมเสนอทางเลือกให้ทันที
>
> **3. คิวทดลองขับที่ชนกันไม่ได้จริง** ถ้ามีคนจองเวลาเดียวกันตัดหน้า ระบบตอบ 409 แล้วรีเฟรชคิวว่างให้ใหม่
> ไม่ใช่รับจองซ้อนแล้วค่อยโทรมายกเลิกทีหลัง
>
> **4. ระบบสมาชิกที่ตรวจสิทธิ์จริง ไม่ใช่แค่มีหน้า login** —
> ผู้ใช้ทั่วไปยกระดับตัวเองเป็น admin ไม่ได้, พอ admin สั่งระงับบัญชี token ที่ค้างอยู่ตายทันที,
> และระบบกันไม่ให้ลบ admin คนสุดท้ายในระบบ ทั้งหมดนี้มีเทสต์อัตโนมัติ 15 เคสคุมไว้"

## 3:00–4:30 — เดโมสด

เปิดไว้ล่วงหน้า 2 แท็บ: `http://localhost:8000/docs` และ `http://localhost:8000`

**A. Swagger UI (~50 วินาที)**

1. `POST /api/register` → Try it out → กรอกข้อมูลใหม่ → ได้ `201` พร้อม token
   *(ชี้ให้ดูว่าใน response ไม่มี password และ role เป็น customer เสมอ)*
2. กด **Authorize** มุมขวาบน วาง token
3. `GET /api/users?page=1&per_page=2` → ชี้ให้ดู `total`, `total_pages` (pagination)
4. `PUT /api/users/{id}` ด้วย `{"role": "admin"}` จากบัญชี customer → **403** — กันยกระดับสิทธิ์
5. `GET /api/check-username/admin` → `available: false`

**B. เว็บจริง (~40 วินาที)**

1. หน้าแรก → กด **สมัครสมาชิก** → พิมพ์ username ที่ซ้ำ ระบบขึ้นเตือนทันทีขณะพิมพ์
   *(ชี้ว่านี่คือ `GET /api/check-username/{name}` ทำงานอยู่เบื้องหลัง)*
2. เข้าสู่ระบบด้วย `admin / admin1234` → ชื่อขึ้นมุมขวาบน
3. หน้า **บัญชีของฉัน** → แท็บ **จัดการผู้ใช้** → ค้นหา / เปลี่ยนหน้า / กดระงับบัญชี

**C. Docker (~15 วินาที)**

```bash
docker compose ps        # เห็น 2 container: astra-web (FastAPI) + astra-db (PostgreSQL)
```

> "ทั้งระบบขึ้นด้วย `docker compose up` คำสั่งเดียว เพื่อนกลุ่มไหนก็รันได้เหมือนกันทุกเครื่อง"

## เตรียมก่อนขึ้นพูด (checklist)

- [ ] `docker compose up --build` แล้วรอจน `astra-web` ขึ้น healthy (ถ้าไม่มี Docker ในเครื่องให้ใช้ `cd backend && uvicorn app.main:app --reload`)
- [ ] เปิด `http://localhost:8000/docs` และ `http://localhost:8000` ไว้ล่วงหน้า
- [ ] `cd backend && pytest -q` ให้เห็น `15 passed` ไว้เป็นหลักฐาน (เผื่ออาจารย์ถาม)
- [ ] เตรียมบัญชีเดโม: `admin / admin1234`
- [ ] ปิดการแจ้งเตือนของเครื่อง + ซูมเบราว์เซอร์ 110–125% ให้คนหลังห้องอ่านออก

## คำถามที่อาจโดนถาม

| คำถาม | คำตอบสั้น |
|---|---|
| ทำไมใช้ token ไม่ใช้ session cookie | frontend เป็นไฟล์ static เรียก API ข้ามหน้า การใช้ Bearer token ทำให้เทสต์ผ่าน Swagger/pytest ได้ตรง ๆ และย้ายไป JWT ภายหลังได้โดยแก้แค่ `security.py` |
| เก็บรหัสผ่านยังไง | PBKDF2-HMAC-SHA256 120,000 รอบ + salt สุ่มรายบัญชี ไม่เก็บ plain text และไม่ส่ง hash ออก API |
| ข้อมูลหายไหมเวลารีสตาร์ต | สัปดาห์นี้เก็บใน memory ตามที่วางไว้ — container `db` (PostgreSQL) เตรียมไว้ใน docker-compose แล้ว สัปดาห์หน้าย้ายลง DB จริง |
| ทำไม `docker compose` ต้องมี 2 service | แยก stateless (API) ออกจาก stateful (ฐานข้อมูล) — ข้อมูลอยู่ใน volume `db_data` ลบคอนเทนเนอร์แล้วข้อมูลไม่หาย และเป็นโครงเดียวกับตอน deploy จริง |
| ต่างจาก Toyota/Honda ที่มีเว็บอยู่แล้วยังไง | เว็บค่ายรถส่วนใหญ่จบที่ "ฝากข้อมูลให้เซลส์ติดต่อกลับ" ของเราทำต่อจนถึงวางเงินจอง ยื่นสินเชื่อ และติดตามผลอนุมัติได้เอง |
