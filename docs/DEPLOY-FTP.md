# เอาขึ้นโฮสต์ที่เข้าได้ทาง FTP อย่างเดียว (FileZilla)

ใช้กับโฮสต์ที่ลากไฟล์ขึ้นได้อย่างเดียว ล็อกอิน SSH ไม่ได้ ติดตั้งโปรแกรมเองไม่ได้
ถ้าโฮสต์มี SSH ให้ดู [DEPLOY-VPS.md](DEPLOY-VPS.md) จะได้ระบบครบในที่เดียว

## สิ่งที่ลากขึ้นไปแล้วทำงาน และสิ่งที่ไม่ทำงาน

ลากขึ้นได้เลย: หน้าเว็บทั้งหมดในโฟลเดอร์ `frontend/` คือ HTML, CSS, JavaScript และโมเดล 3D
เป็นไฟล์ static ล้วน โฮสต์ไหนก็เสิร์ฟได้

ลากขึ้นแล้วไม่ทำงาน: `backend/` ทั้งโฟลเดอร์ ตัว API เป็นโปรแกรม Python (FastAPI) ที่ต้องมี
process รันค้างไว้ บวกกับ PostgreSQL อีกตัว โฮสต์ FTP ล้วนไม่มีทั้งสองอย่าง
การอัปโหลดไฟล์ `.py` ขึ้นไปจะไม่มีอะไรรันมัน หน้าเว็บจะขึ้นแต่กดอะไรก็ขึ้นว่าเชื่อมต่อเซิร์ฟเวอร์ไม่ได้

ทางออกคือวางสองส่วนคนละที่ หน้าเว็บอยู่โฮสต์ FTP ของตัวเอง ส่วน API อยู่ Render ซึ่งรัน Python ได้
และสมัครฟรีไม่ต้องใช้บัตร โค้ดรองรับการแยกแบบนี้แล้ว แก้ค่าเดียวที่ `frontend/js/config.js`

```
เบราว์เซอร์  ──โหลดหน้าเว็บ──▶  โฮสต์ FTP ของเรา   (HTML/CSS/JS/โมเดล 3D)
     │
     └────────เรียก API───────▶  Render               (FastAPI + PostgreSQL)
```

## ขั้นที่ 1: เอา API ขึ้น Render

ทำตาม [DEPLOY.md](DEPLOY.md) หัวข้อ Blueprint จนได้ URL หน้าตาแบบ
`https://astra-motors-xxxx.onrender.com` แล้วเปิด `URL นั้น/api/health` ต้องได้
`{"status":"ok","database":"postgresql"}`

ตอน Apply blueprint Render จะถามค่า `CORS_ORIGINS` ให้ใส่ที่อยู่ของเว็บฝั่งเรา เช่น

```
https://astra.example.com
```

ห้ามมี `/` ปิดท้าย ถ้ามีทั้งแบบมี www และไม่มี ให้ใส่ทั้งสองคั่นด้วยจุลภาค

```
https://astra.example.com,https://www.astra.example.com
```

ค่านี้คือรายชื่อโดเมนที่เบราว์เซอร์ยอมให้เรียก API ข้ามโฮสต์ ถ้าไม่ตั้ง หน้าเว็บจะโดนเบราว์เซอร์บล็อก
ตั้งผิดตัวอักษรเดียวก็บล็อก ตั้งทีหลังได้ที่ Dashboard ของ service หัวข้อ Environment แล้วกด
Manual Deploy หนึ่งครั้ง

## ขั้นที่ 2: บอกหน้าเว็บว่า API อยู่ที่ไหน

เปิดไฟล์ `frontend/js/config.js` ในเครื่อง แก้บรรทัดเดียว

```js
window.API_BASE = "https://astra-motors-xxxx.onrender.com";
```

ข้อควรระวัง
- ห้ามมี `/` ปิดท้าย
- ต้องเป็น `https` ถ้าเว็บของเราเปิดด้วย `https` เบราว์เซอร์บล็อกการเรียก `http` จากหน้า `https`
- ปล่อยเป็นค่าว่างไว้เมื่อไหร่ แปลว่าหน้าเว็บกับ API อยู่โดเมนเดียวกัน (กรณี Docker หรือ Render อย่างเดียว)

## ขั้นที่ 3: ลากขึ้นด้วย FileZilla

1. ต่อ FileZilla เข้าโฮสต์ ตั้ง Protocol เป็น **SFTP** ถ้าโฮสต์รองรับ ถ้ามีแต่ FTP ธรรมดา
   ให้เลือก **FTPS (require explicit TLS)** อย่างน้อยรหัสผ่านจะไม่วิ่งเป็นข้อความธรรมดา
2. ฝั่งขวาเข้าไปที่โฟลเดอร์รากของเว็บ ชื่อมักเป็น `public_html` หรือ `www` หรือ `htdocs`
3. ฝั่งซ้ายเปิดโฟลเดอร์ `frontend` ของโปรเจกต์
4. ลาก **ของข้างในโฟลเดอร์ frontend** ไปวาง ไม่ใช่ลากตัวโฟลเดอร์ `frontend` ไปทั้งก้อน
   ผลที่ถูกต้องคือบนโฮสต์มีหน้าตาแบบนี้

```
public_html/
├── index.html
├── css/
├── js/
├── pages/
└── assets/
```

ถ้าได้เป็น `public_html/frontend/index.html` จะเปิดไม่ขึ้น เพราะทุกหน้าอ้างไฟล์แบบ `/js/...`
ซึ่งนับจากรากของโดเมนเสมอ ด้วยเหตุผลเดียวกัน เว็บนี้ต้องอยู่ที่รากของโดเมนหรือซับโดเมน
วางในโฟลเดอร์ย่อยแบบ `example.com/astra/` ไม่ได้

5. โฟลเดอร์ `assets/models/` ใหญ่ประมาณ 46 MB เป็นไฟล์ `.glb` ของรถ อัปนานหน่อย
   อย่าปิด FileZilla ระหว่างอัป ถ้าหลุดกลางคันให้สั่งอัปซ้ำทับได้

## ขั้นที่ 4: ตรวจว่าใช้ได้จริง

- เปิดเว็บ หน้าแรกต้องขึ้นรถ 4 คัน ถ้าหน้าโล่งแปลว่าเรียก API ไม่ได้
- กด F12 แท็บ Console ต้องไม่มีข้อความสีแดง
- สมัครสมาชิกใหม่ แล้วจองทดลองขับหนึ่งรายการ
- เปิดหน้ารายละเอียดรถ โมเดล 3D ต้องหมุนได้
- ล็อกอิน `admin` / `admin1234` แล้ว **เปลี่ยนรหัสผ่านทันที** รหัส seed อยู่ในโค้ดสาธารณะบน GitHub
  เปลี่ยนของ `somchai` / `somchai123` ด้วย

## เวลาจะแก้เว็บรอบถัดไป

แก้ไฟล์ในเครื่อง แล้วลากทับเฉพาะไฟล์ที่แก้ ไม่ต้องอัปใหม่ทั้งก้อน
ถ้าแก้ไฟล์ใน `css/` หรือ `js/` แล้วเปิดเว็บยังเห็นของเก่า เป็นเพราะเบราว์เซอร์แคชไว้
ทุกหน้าอ้างไฟล์พร้อมเลขเวอร์ชันแบบ `?v=19` ให้ไล่แก้เลขนั้นเป็น `?v=20` ทุกหน้าที่อ้างถึง
แล้วอัปหน้า HTML ขึ้นไปด้วย

ส่วนที่แก้ `backend/` ต้อง `git push` ขึ้น GitHub แล้ว Render จะ deploy ใหม่ให้เอง
ไม่เกี่ยวกับ FileZilla

## ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| หน้าเว็บขึ้นแต่ไม่มีรถ Console ขึ้น `blocked by CORS policy` | `CORS_ORIGINS` บน Render ไม่ตรงกับโดเมนของเว็บเป๊ะ ๆ | เทียบตัวอักษรให้ตรงรวมทั้ง `https` และ `www` ห้ามมี `/` ปิดท้าย แก้แล้วกด Manual Deploy |
| Console ขึ้น `Mixed Content` | เว็บเปิดด้วย https แต่ `API_BASE` เป็น http | แก้ `js/config.js` ให้เป็น https |
| ขึ้น "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้" ทุกปุ่ม | `API_BASE` ว่างหรือสะกดผิด หรือ service บน Render หลับอยู่ | เปิด `<API_BASE>/api/health` ตรง ๆ ดูว่าตอบไหม free tier หลับหลังไม่มีคนเข้า 15 นาที ตื่นครั้งแรกรอ ~1 นาที |
| เปิดเว็บได้แต่ขึ้นหน้าเปล่า Console ขึ้น 404 ของ `/js/...` | อัปทั้งโฟลเดอร์ `frontend` ขึ้นไปแทนที่จะอัปของข้างใน หรือวางไว้ในโฟลเดอร์ย่อย | ย้ายไฟล์ให้ `index.html` อยู่ที่รากของ `public_html` |
| โมเดล 3D ไม่ขึ้น | ไฟล์ `.glb` อัปไม่ครบหรืออัปแบบ ASCII | FileZilla เมนู Transfer ตั้ง Transfer type เป็น **Binary** แล้วอัปซ้ำ |
| จองแล้วข้อมูลหายหลังผ่านไปวันสองวัน | ฐานข้อมูล free ของ Render หมดอายุ 30 วัน | สร้างฐานข้อมูลใหม่แล้ว deploy ซ้ำ ข้อมูล seed กลับมาเอง |
