# User Journey → หน้าจอ → API

User Journey: **ระบบจองทดลองขับและซื้อรถออนไลน์ (Online Test Drive & Car Purchase System)**
จัดทำโดย 67160240 อภิชา วงค์กลาง และ 67160175 อภิภู ก้านสุวรรณ

| # | ขั้นตอน | ผู้ใช้ทำอะไร | Pain point | โอกาสในการพัฒนา (Opportunity) | สิ่งที่ระบบทำได้จริง | หน้าจอ | API |
|---|---|---|---|---|---|---|---|
| 1 | รับรู้ (Awareness) | เห็นโฆษณา โปรโมชั่น รีวิว | ข้อมูลกระจัดกระจาย เปรียบเทียบยาก | รวมข้อมูลรถ รีวิว โปรโมชั่นไว้ในระบบเดียว | หน้าแรกรวมโปรโมชั่นที่ยังไม่หมดอายุ (ซ่อนที่หมดแล้วอัตโนมัติ) + รีวิวล่าสุดจากสมาชิก + คะแนนดาวบนการ์ดรถ | `index.html` | `GET /api/promotions`, `GET /api/reviews` |
| 2 | ค้นหารถ (Browse) | ค้นตามยี่ห้อ รุ่น ราคา ประเภท | ตัวเลือกเยอะ ค้นหายาก | ระบบค้นหาและตัวกรองที่ใช้ง่าย | ช่องค้นหา + กรองยี่ห้อ/ระบบขับเคลื่อน/งบประมาณ + เรียงตามราคา/แรงม้า/0-100/คะแนนรีวิว (ทำใน SQL) | `index.html` | `GET /api/cars?q&brand&drive&max_price&sort`, `GET /api/cars/facets` |
| 3 | ดูรายละเอียด (Car Details) | ดูรูป สเปก ราคา | ข้อมูลไม่ครบ ไม่มีรูปหลายมุม | รูป 360°, วิดีโอ, เปรียบเทียบรุ่น | โมเดล 3D หมุน 360° + เปลี่ยนสี, ราคาอัปเดตตามออปชัน, เทียบ 3 รุ่น, คำนวณไฟแนนซ์, จำลองการใช้งานบนถนนไทย, รีวิวรุ่นนั้น | `model.html`, `compare.html`, `finance.html`, `thai-road.html` | `GET /api/cars/{id}`, `GET /api/finance/plans`, `POST /api/simulation` |
| 4 | จองทดลองขับ (Book Test Drive) | เลือกโชว์รูม วัน เวลา | ต้องโทรเอง เวลาซ้ำกับลูกค้าอื่น | จองออนไลน์ แสดงเวลาว่างเรียลไทม์ | คิวว่างคำนวณจากการจองจริงในฐานข้อมูล — จองซ้ำช่วงเดียวกันได้ 409, ยกเลิกแล้วคิวกลับมาว่าง, guest จองได้/สมาชิกได้คะแนน | `test-drive.html` | `GET /api/showrooms/{id}/slots`, `POST /api/testdrives`, `POST /api/testdrives/{code}/cancel` |
| 5 | ซื้อรถออนไลน์ (Online Purchase) | เลือกรถ กรอกข้อมูล ยืนยันการจอง | ขั้นตอนยุ่งยาก เอกสารเยอะ | กรอกออนไลน์ อัปโหลดเอกสาร ชำระเงินผ่านระบบ | วางเงินจอง (จำลอง PromptPay/บัตร) ล็อกราคา 14 วัน, เติมข้อมูลจากบัญชีให้อัตโนมัติ, อัปโหลดเอกสาร PDF/JPG/PNG จริง (ตรวจชนิดไฟล์), ยื่นสินเชื่อ + ทางเลือกเมื่อไม่ผ่าน | `reserve.html`, `loan.html` | `POST /api/reservations`, `POST /api/documents`, `POST /api/loans` |
| 6 | ติดตามสถานะ (Track Order) | ตรวจสอบสถานะการจอง/สั่งซื้อ | ต้องโทรถามโชว์รูม | แสดงสถานะเรียลไทม์ พร้อมแจ้งเตือน | หน้า "การจองของฉัน" รวมทุกการจองของบัญชี, stepper ใบจอง→สินเชื่อ→รับรถ, ผลสินเชื่ออัปเดตเอง, กระดิ่งแจ้งเตือน + toast เมื่อมีเรื่องใหม่ | `status.html` + กระดิ่งทุกหน้า | `GET /api/me/bookings`, `GET /api/loans/{id}`, `GET /api/notifications` |
| 7 | หลังการใช้งาน (After Sales) | ให้คะแนน รีวิว นัดเข้าศูนย์ | ไม่มีช่องทางติดต่อหรือรีวิว | ระบบรีวิว นัดหมายเข้าศูนย์ สะสมคะแนน | รีวิว 1-5 ดาว (ป้าย "ผ่านการใช้งานจริง"), นัดเข้าศูนย์บริการตามจำนวนช่องซ่อม, คะแนนสะสม + ระดับสมาชิก + แลกของรางวัล | `after-sales.html`, `model.html` | `POST /api/reviews`, `POST /api/service/appointments`, `GET /api/loyalty`, `POST /api/loyalty/redeem` |

ทุกขั้นตอนใช้ระบบสมาชิกร่วมกัน (`login.html`, `register.html`, `profile.html`) — ข้อมูลทั้งหมดเก็บในฐานข้อมูล
