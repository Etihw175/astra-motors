## ส่วนที่เสร็จแล้ว

### ข้อมูลและโครงสร้าง
- ข้อมูลทั้งหมดอยู่ใน PostgreSQL ผ่าน SQLModel (15 ตาราง) — SQLite สำรองตอนรันในเครื่องและรันเทสต์
- Alembic migration 3 รุ่น; ตอน deploy บน PostgreSQL แอปรัน `alembic upgrade head` ให้เองก่อน seed
- `/api/health` ตอบว่าต่อฐานข้อมูลตัวไหนอยู่ ใช้เป็น health check ของ Docker และ Render

### ขั้นตอนที่ 1–3 รับรู้ / ค้นหา / ดูรายละเอียด
- หน้าแรกรวมโปรโมชั่นที่ยังไม่หมดอายุ รีวิวล่าสุด และคะแนนดาวบนการ์ดรถ
- ค้นหา กรองยี่ห้อ/ระบบขับเคลื่อน/งบประมาณ และเรียงลำดับ — ทำใน SQL ทั้งหมด
- ปุ่มติดตามรุ่นที่สนใจ (watchlist) + ตัวกรอง "เฉพาะที่ฉันติดตาม"
- หน้ารายละเอียด: โมเดล 3D หมุน 360° เปลี่ยนสีได้ ราคาอัปเดตตามออปชัน เทียบรุ่น คำนวณไฟแนนซ์
  และจำลองการใช้งานบนถนนไทย

### ขั้นตอนที่ 4 จองทดลองขับ
- คิวว่างคำนวณจากการจองจริง จองซ้อนช่วงเดียวกันไม่ได้ ยกเลิกแล้วคิวกลับมาว่างทันที
- จองแบบไม่ล็อกอินก็ได้ ถ้าล็อกอินจะผูกเข้าบัญชีและได้คะแนนสะสม

### ขั้นตอนที่ 5 ซื้อรถออนไลน์
- ชำระเงินจองผ่าน payment intent: สร้างรายการ → QR พร้อมเพย์ (payload ตามสเปก EMVCo + CRC16) →
  ยืนยัน → ออกใบจอง ใบชำระเงินหมดอายุใน 15 นาที
- อัปโหลดเอกสารจริง ตรวจชนิดไฟล์จาก magic bytes ไม่เกิน 5 MB และแนบเอกสารของคนอื่นไม่ได้
- ยื่นสินเชื่อ ผลพิจารณาบันทึกลงฐานข้อมูล ไม่ผ่านแล้วระบบคำนวณทางเลือกให้และยื่นใหม่ได้

### ขั้นตอนที่ 6 ติดตามสถานะ
- หน้า "การจองของฉัน" รวมใบจอง นัดทดลองขับ และนัดเข้าศูนย์ของบัญชีไว้ที่เดียว
- แจ้งเตือนผ่าน Server-Sent Events ขึ้นทันทีที่เกิดเรื่อง และถอยไปใช้ poll เมื่อสตรีมใช้ไม่ได้

### ขั้นตอนที่ 7 หลังการขาย
- รีวิว 1–5 ดาว พร้อมป้าย "ผ่านการใช้งานจริง" สำหรับคนที่เคยทดลองขับหรือจองรุ่นนั้น
- นัดเข้าศูนย์บริการ จำกัดตามจำนวนช่องซ่อม ยกเลิกได้ และพนักงานปิดงานได้จากหลังบ้าน
- คะแนนสะสม ระดับสมาชิก และแลกของรางวัล ยกเลิกรายการแล้วคะแนนถูกหักคืน

### งานที่รองรับทั้งระบบ
- หลังบ้านพนักงานโชว์รูม: ตัวเลขสรุป คิวทดลองขับ ใบจอง สินเชื่อ และนัดศูนย์ พร้อมตัวกรองและการแบ่งหน้า
- Event bus ภายใน: Notification และ Loyalty รับ event จาก service อื่นโดยไม่ต้องเรียกกันตรง ๆ
- Accessibility: ใช้คีย์บอร์ดได้ทั้งเว็บ โฟกัสชัด modal ล็อกโฟกัส ข้อความผิดพลาดผูกกับช่องกรอก และรองรับจอ 360px
- เทสต์อัตโนมัติ 79 เคส ผ่านทั้ง SQLite และ PostgreSQL 16
